# Monomotions Media

Public, versioned delivery assets for Monomotions websites.

## Scroll story v1

- `film-a-001.webp` through `film-a-061.webp`: Signal to Idea
- `film-b-001.webp` through `film-b-061.webp`: System to Distribution
- `film-c-001.webp` through `film-c-061.webp`: Visibility and the exact Monomotion mark
- 1280 x 720 WebP, sampled at 12 fps from the accepted Magnific/Kling 2.5 masters

The application loads these immutable assets through jsDelivr. Source masters and rejected generations remain private in the Monomotions production archive.
